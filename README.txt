VivaArt V4 — prototype web / PWA préparatoire

CE QUI FONCTIONNE DANS CETTE VERSION
- Accueil responsive et navigation mobile.
- Interface français / anglais.
- Tutoriels illustrés progressifs : lion, chat, portrait.
- Espace de dessin tactile avec gomme, couleurs et export PNG.
- Sauvegarde locale du dessin sur le même appareil/navigateur.
- Page VivaArt Premium présentant les avantages prévus (mode démonstration).
- Fichiers PWA : manifeste et service worker pour mise en cache hors ligne de l'application.

POUR TESTER MAINTENANT
1. Décompresser le ZIP.
2. Ouvrir index.html dans Chrome pour tester les fonctions principales.
3. Pour installer la PWA et tester le cache hors ligne, héberger le dossier sur un site HTTPS puis ouvrir le site dans Chrome et utiliser « Installer l'application ».

CE QUI N'EST PAS ENCORE ACTIVÉ (NE PAS CONFONDRE AVEC UNE FONCTION PRÊTE)
- APK Android natif / signature de publication.
- Publicités réelles : l'emplacement visible est un repère, aucun annonceur ne paie encore.
- Abonnements et paiements Premium : la page est une présentation, aucun paiement n'est possible.
- Génération d'images par IA, comptes utilisateurs et synchronisation cloud.
- Catalogue complet de dessins réalistes au crayon : les trois tutoriels actuels sont des illustrations vectorielles progressives.

PUBLICATION
Cette version est un prototype PWA testable, pas encore un fichier AAB/APK prêt à publier. Avant Google Play, il faudra créer et signer un build Android, compléter les déclarations de confidentialité et de public cible, tester l'application et respecter les règles Play. Pour les nouveaux comptes personnels concernés, Google demande actuellement un test fermé avec au moins 12 testeurs inscrits pendant 14 jours consécutifs avant de demander l'accès à la production.
